# Practice chess openings

## How to use

Type "/chess" inside a document and click enter. <br>
![Step 1](https://raw.githubusercontent.com/eosinophobe/Rem-s-Gambit/main/public/Images/Step%201.png)

Enter the chess opening you want to practice as PGN (Portable Game Notation) with an optional title. Choose if you want to practice the opening as white or as black. <br>
![Step 2](https://raw.githubusercontent.com/eosinophobe/Rem-s-Gambit/main/public/Images/Step%202.png)

This will create a card inside the document. Note that you should never manually change the content of this card. If you need to modify it, delete it and create a new one. <br>
![Step 3](https://raw.githubusercontent.com/eosinophobe/Rem-s-Gambit/main/public/Images/Step%203.png)

Start a flashcard queue as you would with any other document. The flashcard will automatically turn into an interactive chess board where you need to move the pieces according to the PGN. <br>
![Step 4](https://raw.githubusercontent.com/eosinophobe/Rem-s-Gambit/main/public/Images/Step%204.png)

Happy check mating!

## Third party disclaimer

When the board preview is enabled, Rem's Gambit requests a board image from [backscattering.de](https://backscattering.de/web-boardimage/board.png) upon card creation. This request contains the resulting chess position as a FEN string, the image size, the board orientation, and the selected board color theme. **No other content from your knowledge base is shared.**

As with any request to an external website, backscattering.de may receive standard technical information such as the request timestamp, IP address, user agent, and referrer, and may process the request according to its own privacy policy. Disable the board preview setting to prevent this request. **Disabling the board preview will not interfere with the flashcard chess board, as it is run locally.**
